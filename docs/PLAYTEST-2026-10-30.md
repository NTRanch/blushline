# Playtest record — Blushline v1.0.0 (2026-10-30)

Automated playtest of record for the sandbox build (seahawk pass on
primo is the scheduled follow-up, see BREAKAGE-LOG).

## Method

- `node tools/playtest.mjs`: the shipped JS core in demo mode plays
  each level from `start_level` to a terminal screen. Pass = victory
  with the level's tier target reached; level 3 must also complete
  the revelation (every intimate station's gaze read true).
- `node tools/conformance.mjs`: the JS transliteration against the
  Mojo kernel's golden vectors — 100 checks, tolerance 1e-12.
- `node tests/run.mjs`: 22 tests, validation + adversarial split.
- `node tools/settings-check.mjs`: settings bridge round-trip;
  settings reachable from boot without progression.
- `node tools/perf.mjs`: step budget.
- D-221 visual spot check: frames extracted from the final preview
  MP4s at viewing size and inspected — SHOULD: dark plum fitting
  room, centred abstract portrait whose blush and gaze read at a
  glance, the tape across the torso, legible HUD and report text.
  First pass found one FAIL (preview text running off the right edge
  at raster scale — the shared rasteriser's font advance is wider
  than canvas monospace, so lines sized for the canvas overflowed
  the 480px raster), fixed by resizing/repositioning the affected
  lines, re-captured, re-inspected PASS: station HUD, reading and
  gaze report lines, blush bar and tier all legible and complete;
  at L3 the cheeks are large and hot, lids lowered, mouth open at
  T2, iris visibly offset on an AWAY read.

## Results

- Level 1 — First Fitting: VICTORY, 1020 steps, fit 98, max tier T2.
- Level 2 — The Thorough Check: VICTORY, 1500 steps, fit 97, max tier T2.
- Level 3 — Made to Measure: VICTORY, 1968 steps, fit 96, max tier T2,

- Tests: 22 pass (13 validation / 9 adversarial), including the
